# KABARARUS — publication universe

Kabararus is an independent, Indonesian-language newsroom built around a publishing masthead rather than a corporate landing page. The interface uses newsprint white, ink black, and a single signal red. Georgia-based display headlines, reading serif copy, Arial UI controls, and monospace metadata create a layered editorial hierarchy.

The front page follows a lead story + side column + sectional desks grammar. Article pages use byline, timestamp, reading time, progress indicator, pull quote, caption, related coverage, author module, and next article. Data uses a table-first presentation. Search, newsletter, and contact forms are frontend demos with no network calls.

Mobile behavior keeps topic navigation as a horizontal publication rail, collapses the front page into lead then desk stories, and retains article metadata and reading progress. Motion is intentionally minimal; reduced-motion removes smooth scroll and all transitions.
