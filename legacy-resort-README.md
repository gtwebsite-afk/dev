# Aruva — Teluk Timur

A standalone luxury boutique resort showcase for the premium five-site portfolio. The route set is intentionally destination-led: arrival, stay, dining, wellness, experiences, destination, journal, and reservation.

- **Palette:** Ivory `#f7f3eb`, cream `#eee6d8`, sand `#d7c5ac`, botanical green `#243a2d`.
- **Type:** P052 Roman (editorial serif) + Nimbus Sans (quiet utility sans), loaded from the project-level `assets/fonts` directory.
- **Motion:** slow hero drift, intersection-based reveal, image hover crop; reduced-motion fallback included.
- **Navigation:** centered wordmark, split desktop nav, compact sticky header, full-height mobile menu.
- **Routes:** `index.html` plus 29 meaningful interior pages (all links relative and domain-agnostic).
