# Metrika Academy

Creative academy concept site for portfolio display. The interface uses an expressive modular grid instead of a generic card template: cobalt, lime, coral and cream blocks; typographic hierarchy; index lists; editorial works; and an intentionally oversized CTA footer.

## Design system
- **Brand:** Metrika Academy — learning for creative practice.
- **Type:** Display uses a heavy geometric system stack (`Inter`, `Arial Black` fallback); body uses a readable humanist system stack. No runtime font requests.
- **Colors:** Cobalt `#3155FF`, lime `#D7FF55`, coral `#FF735F`, navy `#11152F`, cream `#FFF9ED`.
- **Layout:** 12-column asymmetric program grid, 1px navy rules, square corners, broad negative space.
- **Motion:** Short transform and color transitions, marquee strip, reduced automatically under `prefers-reduced-motion`.
- **Mobile:** Collapsible menu, single-column modules, full-width action buttons, reordered content for thumb reach.
- **Accessibility:** Semantic landmarks, skip link, visible focus rings, labels and native validation, status announcements, Escape-to-close mobile navigation.

All copy, people, events and programmes are fictional. Forms run local validation only and never transmit data.
