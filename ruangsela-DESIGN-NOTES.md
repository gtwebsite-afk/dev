# DEMO 17 — Ruang Sela

Ruang Sela is a fictional contemporary museum concept centered on curatorial indexing. The interface uses a gallery-white / concrete-gray field, museum blue (`#315c72`) and a single vermilion accent (`#d46b4a`). Typography is system grotesk paired with tabular mono labels; no webfont or CDN is required.

The information architecture follows exhibition chronology, collection object records, artists, archive, research, programs, and visit planning. The homepage opens with a catalog-like current exhibition fragment, while detail pages use room numbering, object metadata, and timelines. Cards are replaced by catalog rows, ruled tiles, tables, and timeline markers. Mobile collapses the index into a compact menu and keeps visit, exhibition, and collection paths within one tap.

The site is a static frontend demo. Forms provide local success feedback only and do not send data. `assets/artwork.svg` and `assets/map.svg` are original local vector assets.
