# KYNTRA Automotive Demo

KYNTRA adalah concept brand kendaraan listrik performa tinggi dengan art direction carbon, titanium, dan signal orange. Semua halaman berjalan sebagai static HTML tanpa build process, CDN, API, atau kredensial.

## Halaman
Home, Models, PULSE-01, APEX-02, VECTOR-03, Compare, Configure, Engineering, Performance, Battery, Charging, Safety, Design, Ownership, Service, Warranty, Locations, Test Drive, Stories, FAQ, Contact, Privacy, Terms, dan 404.

## Interaksi
Model switcher, perbandingan model, konfigurator client-side, menu responsif, indikator progres baca, dan form demo dengan status aksesibel.

## Aksesibilitas dan performa
Semantic landmarks, skip link, visible focus browser default, label form, aria-live, prefers-reduced-motion, layout tanpa horizontal overflow, dan asset visual berbasis CSS/SVG lokal.
